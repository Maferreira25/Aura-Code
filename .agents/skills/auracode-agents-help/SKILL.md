# Aura Code — Catálogo de Agentes Especiais (`auracode-agents-help`)

O **Aura Code** organiza seu trabalho utilizando um "time de especialistas virtuais". Cada agente possui responsabilidade e limites declarados; nenhum deles substitui as provas exigidas pelo fluxo.

---

## 👥 Conheça o Time Virtual do Aura Code

1. **`auracode-clarify` (O Entrevistador Didático)**:
   - *Analogia*: É como o arquiteto paciente que faz perguntas sobre os hábitos da sua família antes de desenhar a casa.
   - *Função*: Faz perguntas simples sem termos difíceis para entender exatamente o que você quer construir.

2. **`auracode-brainstorm` (O Mestre de Ideias)**:
   - *Analogia*: É o consultor de novos negócios que ajuda você a colocar a ideia no papel.
   - *Função*: Transforma vontades abstratas em uma lista organizada de funcionalidades.

3. **`auracode-architect` (O Engenheiro Calculista)**:
   - *Analogia*: É o engenheiro responsável por calcular a estrutura, a fiação e o encanamento.
   - *Função*: Desenha a Planta Teórica Completa em `_auracode_sdd/` cobrindo segurança, telas e banco de dados.

4. **`auracode-writer` (O Mestre de Obras)**:
   - *Analogia*: É o construtor experiente que ergue as paredes seguindo rigorosamente a planta aprovada.
   - *Função*: Escreve o código limpo, sem desperdício e com tipagem segura.

5. **`auracode-reviewer` / `auracode-audit` (O Fiscal da Defesa Civil)**:
   - *Analogia*: É o inspetor de obras que testa a resistência das paredes, caixa d'água e fiação antes da entrega.
   - *Função*: Executa as garantias aplicáveis e mostra `PASS`, `FAIL`, `NOT_RUN`, `NOT_APPLICABLE` ou `ERROR` com evidência.

6. **`auracode-debugger` (O Técnico de Reparos)**:
   - *Analogia*: É o encanador/eletricista chamado para encontrar a causa exata de uma infiltração e consertar na hora.
   - *Função*: Identifica defeitos, cria testes que reproduzem o erro e aplica correções cirúrgicas.
