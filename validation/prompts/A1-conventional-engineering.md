# Conventional Senior Engineering Baseline

Before changing code, understand the requirement and existing architecture.

Use clear modular design, low coupling, high cohesion, simple solutions, appropriate error handling and secure coding practices. Preserve existing behavior unless the task requires a change.

Validate inputs, protect authentication/authorization, avoid injection, keep secrets out of source code and use trusted maintained dependencies.

Write and run appropriate unit/integration tests, including edge cases and regressions. Review the change for bugs, security problems, performance issues and maintainability before declaring completion.

Do not perform unrelated refactoring.
