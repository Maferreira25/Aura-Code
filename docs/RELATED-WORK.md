# Related Work

This project exists in an active and rapidly evolving field. It does not claim that evidence-gated agentic development was invented here.

Examples of related or contemporaneous work include:

- **Agentic Engineering Manifesto** — specification-first and evidence-oriented engineering principles for agentic development: https://arnaudgelas.github.io/agentic-engineering-manifesto/
- **Proof-or-Stop** — research on evidence-gated lifecycle claim admissibility for autonomous agents: https://arxiv.org/abs/2607.14890
- **Softsensor Concord** — governed execution/evidence tooling for agentic delivery: https://www.softsensor.ai/concord
- NIST SSDF, OWASP, OpenSSF, SLSA, CycloneDX, CISA Secure by Design and Google SRE, referenced in the framework source registry.

## Distinguishing scope of this draft

The framework's intended contribution is a vendor-neutral **software assurance control catalog** that combines:

1. ordinary professional software engineering;
2. agent-specific failure controls;
3. assurance levels;
4. lifecycle gates;
5. explicit claim/evidence/verification/blocking semantics;
6. machine-readable controls/profiles;
7. empirical LLM failure-mode mapping;
8. production/SRE and supply-chain assurance;
9. adapters for coding agents without making a single tool normative.

The project should continue comparing itself with related work and incorporate superior ideas through attributed, evidence-based proposals rather than claiming artificial novelty.
