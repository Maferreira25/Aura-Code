# Glossary

**Agent** — AI system able to plan and take tool actions, not merely produce text.

**Assurance** — justified confidence supported by evidence; not absolute certainty.

**Assurance case** — structured claim supported by evidence and decision rules.

**Blocking condition** — condition that prevents merge/release unless a valid exception mechanism permits otherwise.

**Evidence** — artifact or observation that can support/refute a control claim.

**Held-out test** — evaluation case unavailable to the implementing agent for modification (and sometimes content visibility).

**Independent oracle** — source of expected correctness not derived solely from the implementation being judged.

**Invariant** — property that must remain true across system states/changes.

**Least agency** — limiting an autonomous agent's action scope, duration and consequential freedom in addition to conventional least privilege.

**Mutation testing** — deliberately introducing small faults to determine whether tests detect them.

**Provenance** — verifiable information about where/how an artifact or change was produced.

**Reward hacking** — optimizing an evaluator or loophole instead of the intended task outcome.

**SBOM** — machine-readable inventory of software components/dependencies.

**SLO** — measurable reliability target for a service indicator.

**Waiver** — time-bounded, accountable acceptance of a control deviation with documented risk.
