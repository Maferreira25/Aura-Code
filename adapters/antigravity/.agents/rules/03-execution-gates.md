# Execution Gates — Always On

For non-trivial work:
G0 risk → G1 requirements/acceptance → G2 architecture/threat → G3 implementation → G4 verification → G5 release evidence → G6 production feedback.

Before implementation, identify applicable controls from `controls/catalog.json`.

After implementation:
- execute objective verification;
- verify evaluator/test integrity;
- request independent review for significant work;
- produce evidence records for blocking controls.

Do not declare completion while an applicable blocking condition remains.
