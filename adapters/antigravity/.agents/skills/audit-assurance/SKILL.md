---
name: audit-assurance
description: Audit an existing project against a selected AI Software Assurance Framework profile without silently refactoring it.
---

1. Validate selected AL against actual risk.
2. Map architecture, data/trust boundaries and AI/tool permissions.
3. Assess each included control PASS/FAIL/NA/NOT_ASSESSED.
4. Demand evidence; agent assertions are not evidence.
5. Map findings to controls and severity.
6. Prioritize security/integrity/evaluator/supply-chain issues first.
7. Produce assessment JSON and remediation plan.
8. Do not call the result certification.
