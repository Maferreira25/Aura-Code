---
name: feature-assurance
description: Develop a new feature under the AI Software Assurance Framework with requirements, risk, architecture, security, verification and evidence gates.
---

1. Inspect existing implementation and architecture.
2. Classify the change/assurance level.
3. Resolve material ambiguity with the user in plain language.
4. Define observable acceptance criteria and touched invariants.
5. Identify applicable controls and required evidence.
6. Threat-model if security-sensitive/internet/data boundary changes.
7. Plan minimum coherent implementation.
8. Implement without unrelated refactor.
9. Run applicable tests/scans; do not modify protected evaluator to pass.
10. Ask an independent reviewer for significant changes.
11. Create/update assessment/evidence artifacts.
12. Report evidence, residual risk and limitations.
