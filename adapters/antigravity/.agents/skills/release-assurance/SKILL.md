---
name: release-assurance
description: Build a release-readiness evidence package and block release when applicable framework controls, recovery or independent approval are missing.
---

Verify:
- requirements and acceptance;
- tests and evaluator integrity;
- security and dependency findings;
- artifact identity/SBOM/provenance as applicable;
- migration/rollback;
- load/reliability evidence;
- open waivers;
- approval separation.

Never release because the implementing agent says the change is ready.
