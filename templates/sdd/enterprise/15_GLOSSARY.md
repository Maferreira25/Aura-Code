# Glossário Ubíquo do Domínio (15 — GLOSSARY)

> **Metodologia:** Domain-Driven Design (DDD) — Linguagem Ubíqua  
> **Objetivo:** Estabelecer vocabulário único e inequívoco compartilhado entre humanos, especialistas de negócio e agentes de IA.

---

## 1. Termos de Negócio
| Termo | Definição Didática e Inequívoca | Sinônimos Permitidos | Sinônimos Proibidos |
| :--- | :--- | :--- | :--- |
| **Pedido** | Solicitação formal de compra de produtos realizada por um cliente com itens, valores e endereço de entrega. | Ordem de Compra | Carrinho, Cesta |
| **Estoque** | Quantidade física disponível de determinado produto no armazém para venda imediata. | Saldo Disponível | Reserva, Lote |
| **Liquidação** | Confirmação efetiva do pagamento e liberação do pedido para separação. | Faturamento | Pré-autorização |

---

## 2. Termos Técnicos do Framework
| Termo | Significado no Projeto |
| :--- | :--- |
| **AST** | Árvore Sintática Abstrata: análise matemática do código sem executá-lo. |
| **Worktree** | Diretório físico paralelo isolado do Git para o agente trabalhar com segurança. |
| **Jaula (Cage)** | Ambiente hermético DevContainer com firewall bloqueando conexões externas não autorizadas. |
